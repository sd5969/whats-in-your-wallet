Vibecoding in Practice 3
AI-generated code is fast code — not automatically good code
Dead code and legacy artifacts accumulate quickly
Vestigial database drivers, unused imports, and orphaned logic persist unless actively pruned. Technical debt accrues by default.
Debug loops can waste time and deepen debt
When the agent enters a retry spiral on a complex bug, it often produces workarounds rather than root-cause fixes — increasing fragility.
Complex implementation paths need human blocking
Architecture decisions — data models, API contracts, state management — require deliberate design. AI defaults to the simplest working solution.
Front-end quality required manual takeover
Responsive layouts, data visualization, and interaction design still demand human judgment. The AI produced functional but unpolished UI.
Vibecoding in Practice 4
Production guardrails are non-negotiable — speed scales only when governance scales with it
Secrets & Repository Hygiene
No credentials in version control
.env files excluded from commits
Branch protection and signed commits
Dependency audit before production deploy
Security & API Hardening
Input validation at all API boundaries
Session management with signed cookies
Rate limiting and CORS enforcement
HTTPS + reverse proxy for all traffic
High Availability & Reliability
Systemd service with auto-restart
Process supervision and crash recovery
Structured error logging
Build and deploy pipeline with rollback
Working model: Free-form, agent-led exploration for POCs and internal tools — structured, step-by-step with human review checkpoints for anything production-facing or client-visible.
